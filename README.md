# ms-spring-template

Template Spring REST API com Gradle.

## Estrutura

```text
src/
  main/
    java/com/ourosapp/springtemplate/
  test/
```

## Rotas

- `GET /`
- `GET /health`

## Como rodar

```bash
./gradlew bootRun
./gradlew test
./gradlew build
```

## Docker

```bash
docker compose up --build
```
